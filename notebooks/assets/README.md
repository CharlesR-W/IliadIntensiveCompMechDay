# Notebook source assets

`shai_et_al_2024_figure_{1..7}.png` are the seven main figures from Shai et
al., [*Transformers Represent Belief State Geometry in their Residual
Stream*](https://arxiv.org/html/2405.15943) (NeurIPS 2024,
arXiv:2405.15943), downloaded from the official arXiv HTML extraction.

Notebook 2 embeds Figures 1, 3, 4, 5, 6, and 7. It first uses cropped copies of
Figure 5B and Figure 5A as the target simplex and Mess3 orientation images,
then reveals the theory, method, controls, and RRXOR evidence at the matching
points in the guided-discovery sequence. Figure 2 is retained with the source
set but is not embedded because Notebook 1 already supplies that Z1R HMM and
matrix orientation.

The complete official proceedings paper is stored at
`../../papers/shai_et_al_2024.pdf` for offline checking.
